An interactive demonstration showing how readable information is transformed into protected ciphertext and recovered through decryption using a cryptographic key.

What is happening?

Plaintext Readable information
→
Encryption Algorithm + key
→
Ciphertext Protected information
→
Decryption Key + algorithm
→
Plaintext Recovered information
