# Cryptography, Blockchain and Decentralized Technologies Learning Journey

A structured learning journey to understand **cryptography, blockchain, distributed systems, decentralized technologies, and their related security concepts**, starting from the fundamentals and progressing toward advanced topics.

This repository will document my learning day by day, with each stage building upon the knowledge developed previously.

## Goals

* Build a strong mathematical foundation for cryptography.
* Understand the fundamental principles of modern cryptography.
* Learn how encryption and decryption work.
* Understand symmetric and asymmetric cryptography.
* Learn about cryptographic hash functions.
* Understand digital signatures and authentication.
* Learn about public-key infrastructure and certificates.
* Understand cryptographic protocols and secure communication.
* Develop an understanding of cryptographic security principles.
* Understand the fundamentals of blockchain technology.
* Learn how distributed ledgers work.
* Understand blockchain architecture and transaction processing.
* Learn about distributed consensus mechanisms.
* Understand Proof of Work, Proof of Stake, and other consensus approaches.
* Learn how cryptography enables blockchain systems.
* Understand smart contracts and decentralized applications.
* Explore Web3 and decentralized technologies.
* Understand blockchain security and common vulnerabilities.
* Learn about zero-knowledge proofs and privacy-preserving technologies.
* Understand decentralized identity and related technologies.
* Explore decentralized finance and tokenization at a conceptual level.
* Understand the impact of quantum computing on modern cryptography.
* Learn about post-quantum cryptography.
* Develop the ability to read and understand technical material related to cryptography, blockchain, and decentralized systems.

## Learning approach

The repository will follow a progressive learning approach:

**Fundamentals → Mathematics → Cryptography → Distributed Systems → Blockchain → Consensus → Smart Contracts → Security → Privacy → Advanced Technologies → Research**

Each day will build upon the previous day's learning, creating a continuous record of progress from beginner level toward advanced understanding.

## Long-term goal

To develop a comprehensive understanding of **cryptography, blockchain, decentralized systems, privacy technologies, and their security foundations**, combining mathematical concepts, theoretical knowledge, technical understanding, practical learning, and emerging research.
